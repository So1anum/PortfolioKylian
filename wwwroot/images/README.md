# Images du Portfolio

## Photo de profil

Placez votre photo de profil dans ce dossier avec le nom : **`profile-photo.jpg`**

### Recommandations :
- **Format** : JPG ou PNG
- **Dimensions** : Minimum 500x500 pixels (idéalement 800x800 pixels ou plus)
- **Aspect** : Image carrée (ratio 1:1)
- **Qualité** : Haute résolution pour un rendu optimal
- **Fond** : De préférence un fond neutre ou professionnel

### Alternative :
Si vous souhaitez utiliser un autre nom ou format, modifiez la ligne suivante dans `Components/Pages/Home.razor` :
```razor
<img src="images/VOTRE-NOM-IMAGE.jpg" alt="Kylian Debonne" class="profile-image" />
```

### Si vous n'avez pas encore de photo :
Le cercle animé restera visible avec les effets de gradient bleu/violet jusqu'à ce que vous ajoutiez votre photo.
