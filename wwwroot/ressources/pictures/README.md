# ⚠️ IMPORTANT : Copiez votre photo ici !

## Action requise :
Copiez votre fichier **`profile-photo.jpg`** dans ce dossier.

## Chemin attendu :
```
wwwroot/ressources/pictures/profile-photo.jpg
```

## Si votre image est ailleurs :
Si votre image est actuellement dans un autre dossier (en dehors de `wwwroot`), vous devez la **copier** ici.

### Exemple de commande PowerShell :
```powershell
Copy-Item "CHEMIN_VERS_VOTRE_IMAGE\profile-photo.jpg" -Destination "wwwroot\ressources\pictures\profile-photo.jpg"
```

## Formats acceptés :
- JPG, JPEG, PNG, WebP
- Dimensions recommandées : 800x800 pixels minimum
- Format carré (ratio 1:1) pour un rendu optimal

## Vérification :
Une fois l'image copiée, rechargez votre page web et l'image devrait apparaître dans le cercle animé !
